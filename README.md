# 数字千年计划

🌐 [English](README_EN.md)

## 🧭 这是什么

数字千年计划是一项长期开放实践，尝试把人类在真实生活中积累的实用智慧，逐步转化为人能够理解、AI 能够使用的能力。

这些智慧来自经验、书籍、研究、标准和方法论。项目关注的不是把材料简单收集起来，而是记录它们如何被提炼、来源如何说明、结果如何接受反馈，以及能力如何在使用中修订和演化。

这里的仓库是项目的基础设施。它不是另一个 Skill 仓库，也不是 Skill 下载站。Skill 只是这套持续转化过程产生的一种成果，不代表整个项目本身。

## 🧩 Skill 如何形成

一个 Skill 可能从一段经验、一部书、一次研究或一套方法开始。它需要经过提取和整理，保留来源与形成过程，再通过真实使用获得反馈，随后不断修订和演化。

这套过程仍在形成中，相关协议和标准都没有被假定为最终版本。项目更关心哪些内容能够被人读懂、被 AI 正确使用，并且能够在实践中得到检验。

## 🌱 当前阶段

项目目前处于早期阶段，正在建立第一个参考 Skill，并通过真实使用和反馈逐步打磨标准。

早期审核会保持轻量，主要检查规范、格式和来源声明。这里暂不设置复杂的委员会或投票机制。随着实际使用和反馈积累，规则会继续调整。

无论来自什么职业、专业训练或生活背景，只要愿意分享实践中的判断和方法，都可以参与观察、讨论或提出想法。项目暂不宣称已经形成一套固定的贡献流程。

## 🗺️ 未来的索引方向

随着内容增多，项目可能采用一个可扩展的矩阵来组织和连接 Skill。矩阵的一侧是应用领域，另一侧是认知与行动能力，例如理解、判断、规划或执行。它不是已经完成的分类定义，而是一个留待实践检验的方向。

## 👀 先来看看

你可以先关注项目的早期变化，参与讨论，或者提出一个值得提炼的实践想法。项目会在使用和反馈中继续学习，而不是先把所有规则写完再开始。
