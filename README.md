# 数字千年计划

🌐 [English](README_EN.md)

## 🧭 这是什么

一个维修工听见机器的声音，就知道故障可能还没发展到仪表能显示的程度；护士交班时知道哪件事不能省略；老师从学生突然沉默的地方看出他没有跟上；农民从天气、土壤和作物的变化判断什么时候该等一等；办公室里的人也可能从一次会议中没有说出口的话，察觉项目正在冒险。

这类知识往往没有写进书里。它藏在动作、判断、顺序、例外和多年形成的感觉中。当一个人换工作、退休，甚至离世，这些知识可能就没有机会交给下一个人。它们不因为来自哪个职业、行业、职位、教育背景、语言或国家而有高低之分。用双手工作的人、做研究和写作的人，以及照护、教学、建造、组织、维修、种植或创作的人，都可以分享自己的经验，也都应该能够使用由这些经验形成的成果。

分享和使用不该有职业门槛。我们希望这些来自世界各地的知识，不只留在个人手中，也不只服务某一种行业，而能成为劳动者、知识分子和所有实践者都可以贡献、使用并继续修正的公共财富。

数字千年计划是一项仍在早期的开放实践，想做的是给这些经验一个可以逐步说清楚、组织起来、在使用中检验并接受修正的地方。最终形成的 Skill，应该既方便人阅读，也能被 AI 使用。但贡献者不需要先学会写出一份完整 Skill，经验在整理之前就有价值。

这里的仓库是这项工作的基础设施。它不是另一个 Skill 仓库，也不是 Skill 下载站。Skill 只是经验经过描述、结构化、使用检验和持续修订后可能产生的一种成果，项目远不止于此。

## 🧩 Skill 如何形成

一个 Skill 可以从一段工作经验、一部书、一次研究、一项标准或一套方法开始。先把原本只在当事人脑中的判断说出来，再整理适用条件、步骤、例外和来源，形成别人能够读懂的描述。之后通过实际使用发现遗漏和误解，再把反馈写回去。它不是一次写完的说明书，而是会随着使用被检验和修订的知识工具。

这套协议、格式和分类方式仍在形成中，没有哪一项应被视为最终版本。我们先保留轻量的早期审核，主要看规范、格式和来源声明，不设复杂的委员会或投票机制。这样做不是假定判断已经足够完善，而是让内容先有机会进入真实使用，再根据问题修正规则。

## 🌱 当前阶段

项目目前处于早期阶段，正在建立第一个参考 Skill，并通过真实使用和反馈逐步打磨标准。贡献流程、协议和分类尚未定稿。

如果你只知道一个判断是怎样在现场做出的，却还不会把它写成 Skill，也没有关系。你可以先带来一个场景、一段经验或一个值得验证的做法。它是否适用、怎样表达、哪些地方需要补充，可以在后续整理和使用中逐渐变清楚。

## 🗺️ 未来的索引方向

随着内容增多，项目可能采用一个可扩展的矩阵来组织和连接 Skill。一侧可以描述应用领域，另一侧可以描述理解、判断、规划或执行等认知与行动能力。这个方向还需要通过实际内容检验，不是已经完成的分类定义。

## 👀 先来看看

你可以先看看项目正在形成的参考 Skill，参与讨论，或者提出一段值得提炼的实践经验。这里不要求先把所有规则写完才开始，规则会和内容一起，在使用和反馈中慢慢成形。
